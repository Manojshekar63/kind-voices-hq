# Feedback Hub Pro

Create a feedback management web app with a landing page, login/signup pages, and a dashboard with a sidebar and navbar. Use a clean, modern SaaS design with a blue/indigo primary color. Set up React Router routes for: /, /login, /signup, /dashboard, /dashboard/feedback, /dashboard/settings, /dashboard/profile.

This project was built with [Lovable](https://lovable.dev).
